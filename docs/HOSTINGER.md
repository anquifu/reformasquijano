# Publicar la web sencilla

Utilizar **Reformas-Quijano-SENCILLA.zip**. Es el paquete listo para subir, con `index.html` en la raíz; sustituye a los paquetes anteriores.

1. En Hostinger, abrir o crear un sitio de **hosting web HTML/PHP convencional** para `reformasquijano.online`. No elegir la aplicación Node ni importar el repositorio de GitHub. Aunque el panel lo llame «PHP/HTML», esta web no ejecuta PHP.
2. En el Administrador de archivos, entrar en `public_html`. Si contiene archivos, guardar una copia antes de reemplazarlos. Subir el ZIP y extraer **su contenido** ahí: `public_html/index.html`, sin una carpeta intermedia. Incluir `.htaccess`.
3. Abrir `https://reformasquijano.online/` y comprobar el diseño, una página de servicios, teléfono y WhatsApp. Eliminar el ZIP del directorio público después de extraerlo.

No hay comandos de arranque, variables de entorno ni archivo de entrada que configurar. Tampoco hay correo de formularios que activar. No modificar los registros de correo para subir esta web.

El paquete tiene nueve URLs en el sitemap y permite su indexación. El aviso legal y la privacidad siguen pendientes de completar y revisar. La prueba pública solo puede darse por terminada después de subir los archivos y comprobar el dominio.

Si no aparece el Administrador de archivos o la opción de sitio HTML/PHP en el plan, pedir a soporte de Hostinger que habilite un sitio de hosting web convencional para ese dominio.
